# Design System

## 品牌定位

陪伴成长，而不是监督打卡。

让用户每天打开时感到平静、温暖、有希望。

整体风格：

东方极简（Minimal）
自然（Nature）
留白（Breathing）
治愈（Healing）

---

## 页面风格

留白充足

减少视觉噪音

避免复杂动画

避免大面积纯绿色

避免鲜艳色彩

让用户每天愿意打开。
